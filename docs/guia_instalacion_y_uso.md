# Guía de instalación y uso de CBAS

La guía vigente está en el [README del proyecto](../README.md).

Incluye instalación en Windows y Linux/macOS, configuración OAuth, comandos de arranque y verificación, uso del explorador, pruebas y solución de errores. Las rutas son relativas a la carpeta donde clones el repositorio.

La variable del servidor es CBAS_BACKEND_PORT.
